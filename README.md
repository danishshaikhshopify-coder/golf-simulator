# Fairway Growth

A scroll-driven, cinematic one-page marketing presentation for a 90-day Sales Growth Partnership, built for golf simulator dealers, retailers, and resellers.

## Stack

- [Next.js](https://nextjs.org) (App Router, TypeScript)
- [Tailwind CSS v4](https://tailwindcss.com)
- [GSAP](https://gsap.com) + ScrollTrigger for scroll-based animation
- [Lenis](https://github.com/darkroomengineering/lenis) for smooth scroll
- [Lucide](https://lucide.dev) icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

The page is composed of sections under `src/components/sections/`: Hero, Problems, WhoWeHelp, Promise, Strategy, Partnership, Guarantee, and Decision, assembled in `src/app/page.tsx`.
